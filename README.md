# QR Code Generator 🔳✨

A simple, fast, and fully client‑side QR code generator built using pure HTML, CSS, and JavaScript. This repository contains multiple versions of the tool, each representing a different stage of UI experimentation, layout refinement, and feature testing.

## 🚀 Overview
This project allows users to:
- Enter any text or URL  
- Instantly generate a QR code  
- View multiple UI variations across versions  
- Explore different approaches to layout, styling, and interaction  

No frameworks, no dependencies — just clean, lightweight front‑end code.

## 📁 Project Structure
The repository includes several HTML files:

qr code 0.html
qr code 1.html

...
qr code 11.html


Each version explores differences in:
- Layout and spacing  
- Button and input styling  
- QR code rendering approaches  
- Visual hierarchy and responsiveness  

## ▶️ How to Use
1. Clone or download the repository  
2. Open any `.html` file in your browser  
3. Type text or a URL into the input field  
4. Click the generate button to create a QR code  

Every version works independently — choose the one you like best or use them as templates for your own projects.

## 🛠 Customization
Because the project is fully client‑side, you can easily:
- Change color schemes  
- Adjust sizing and spacing  
- Swap QR code libraries or rendering methods  
- Integrate the generator into larger applications
